# Virtualised Insider-Threat Digital Forensics Training Environment

PowerShell automation scripts for constructing and operating a virtualised insider-threat scenario, developed as the practical artefact for an MSc Cyber Security dissertation at Leeds Beckett University.

---

## Overview

This project provides a low-cost, reproducible virtual environment for practical cybersecurity investigation training. It simulates a fictional logistics company in which a trusted employee, holding legitimate but non-administrative access, exfiltrates confidential data. The scenario generates authentic forensic evidence across disk, memory and network sources, allowing students to reconstruct the incident using standard forensic tooling.

The environment is built entirely with free and open-source tools and runs on a single host machine.

---

## Environment Architecture

| Host | Role | Operating System |
|------|------|------------------|
| APEX-DC01 | Domain controller (Active Directory, DNS) | Windows Server 2022 |
| APEX-WS01 | Domain-joined workstation | Windows 11 Enterprise |
| Kali | Controlled exfiltration destination | Kali Linux |

All three machines run on an isolated VirtualBox internal network with **no connectivity to the host machine or the internet**.

---

## Scripts

### `01_Infrastructure_Setup_v2.ps1`
Builds the Active Directory structure:
- Six departmental organisational units
- Six security groups
- Twelve user accounts with department and role attributes
- Departmental SMB shares with matching NTFS and share-level permissions

Includes execution transcript logging, per-operation error handling and execution timing.

**Run on:** the domain controller, as a domain administrator.

### `02_Enterprise_Population.ps1`
Populates the departmental shares with thirty-one business documents backdated across a three-month period, establishing a credible operational history. Documents are generated as valid `.docx`, `.xlsx`, `.pdf` and `.txt` files with author metadata and backdated timestamps.

**Run on:** the domain controller, after Script 01.

### `03_Insider_Activity_Simulation.ps1`
Executes the insider-threat scenario:
1. Baseline legitimate activity across several simulated days
2. Access to four confidential target files
3. Staging and compression into a single archive
4. Transfer to a simulated removable volume
5. Network exfiltration to the controlled destination
6. Attempted clearing of the Windows Security event log

The account used holds legitimate but **non-administrative** privileges. The log-clearing attempt is therefore expected to fail, leaving the audit trail intact — this is a deliberate design outcome, not an error.

**Run on:** the workstation, as the simulated insider, in a standard (non-elevated) session.

## Prerequisites

- Oracle VM VirtualBox
- Windows Server 2022 and Windows 11 Enterprise (evaluation editions are sufficient)
- Kali Linux with Samba configured to serve a guest-accessible share
- An isolated VirtualBox internal network
- A secondary virtual disk attached to the workstation, formatted and mounted as the simulated removable volume

---

## Usage

Run the scripts in order, taking a VirtualBox snapshot after each stage so the environment can be restored to a known state:

```powershell
# On the domain controller
Set-ExecutionPolicy RemoteSigned -Scope Process -Force
.\01_Infrastructure_Setup_v2.ps1
.\02_Enterprise_Population.ps1

# On the workstation, as the simulated insider
.\03_Insider_Activity_Simulation.ps1
```

Before running Script 03, start a packet capture on the isolated network if network evidence is required.

## Forensic Analysis

Evidence generated by the scenario can be examined using:

- **Autopsy** — disk image analysis (LNK artefacts, ShellBags, file-system records, event logs)
- **Volatility 3** — memory image analysis
- **Wireshark** — network capture analysis
- **FTK Imager** — forensic disk acquisition and hash verification
- **Magnet RAM Capture** — memory acquisition

Acquire evidence volatile-first (memory, then network capture, then disk image) and verify the integrity of each item using cryptographic hashing before analysis.

## Safety Notice

These scripts simulate unauthorised data access and exfiltration. They are intended **solely** for use within an isolated laboratory environment for educational purposes.

- Do not run these scripts on production systems or any network with external connectivity
- All data generated by the environment is entirely fictional
- The environment must remain isolated throughout
